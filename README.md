### 🚀 Кто я

Full-Stack разработчик, создаю мобильные приложения, backend-системы и современные веб-интерфейсы. Мне нравится проходить весь путь продукта — от архитектуры и проектирования API до готового пользовательского опыта и деплоя.

### 🧩 Над чем работаю сейчас

- **BalancePsy** — стартап-продукт, разрабатываю мобильную, backend и веб части
- **[NomadCloud.kz](https://nomadcloud.kz/)** — коммерческий веб-проект
- **Veya** — мой собственный full-stack продукт: отдельные mobile, backend и web приложения

Мультиплатформенный продукт, где я закрываю весь технический стек:

- 📱 **Mobile:** Flutter, Dart

- 🌐 **Web:** Vue.js, Nuxt
- 🐳 **Infra:** Docker, Linux, GitHub
